# Foxytrailz23

A canvas-based video transform playground that demonstrates:

- `context.scale(x, y)`
- `context.rotate(angle)`
- `context.translate(x, y)`
- `context.transform(a, b, c, d, e, f)`
- `context.getTransform()`
- `context.setTransform(a, b, c, d, e, f)`
- `context.resetTransform()`

## Run locally

Open `index github.html` in a modern browser, upload a video file, and use the controls to transform the canvas rendering in real time.
